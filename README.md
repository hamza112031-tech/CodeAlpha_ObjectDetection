# 🚀 AI Object Detection & Tracking using YOLOv8

A real-time AI-powered Object Detection and Tracking system built with **Python**, **YOLOv8**, and **OpenCV**.

The application detects and tracks multiple objects in videos while displaying annotated bounding boxes, object labels, and the total number of detected objects.

## ✨ Features

- 🔍 Real-time Object Detection
- 🎯 Multi-Object Tracking
- 📦 Bounding Boxes with Labels
- 📊 Live Object Counter
- 🎬 Video Input & Output Support
- ⚡ Powered by YOLOv8
- 🖥️ Clean Visualization using OpenCV

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/hamza112031-tech/CodeAlpha_ObjectDetection.git
```

Move into the project

```bash
cd CodeAlpha_ObjectDetection
```

Install dependencies

```bash
pip install -r requirements.txt
```

Download the YOLOv8 model

```python
from ultralytics import YOLO

YOLO("yolov8m.pt")
```

---

## ▶️ Run

```bash
python app.py
```
